Para abrir o projeto e rodá-lo em um **computador novo**, você só precisa seguir os passos abaixo:

---

### Pré-requisitos na máquina nova

* Certifique-se de ter o **Git** e o **Docker Desktop** instalados na nova máquina.

---

1. **1. Clone o repositório do GitHub:**
Abra o terminal na pasta onde quer salvar o projeto e faça o clone:

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git

```

*(Substitua a URL acima pelo link do seu repositório no GitHub)*


2. **2. Entre na pasta do projeto:**
Navegue até a pasta interna onde estão o `package.json` e o `Dockerfile`:

```bash
cd Purpuzure/purpuzure

```


3. **3. Gere a imagem Docker:**
Rode o comando de build (o Docker vai baixar o Node, instalar as dependências, criar o build do React e configurar o Nginx automaticamente):

```bash
docker build -t purpuzure-app .

```


4. **4. Inicie o container:**
Execute o container mapeando a porta local:

```bash
docker run -d -p 8080:80 --name container-purpuzure purpuzure-app

```


5. **5. Acesse no navegador:**
Abra o navegador e acesse:
**`http://localhost:8080`**


---

> **Vantagem do Docker:** Você não precisa instalar Node.js nem rodar `npm install` na máquina nova. Todo o ambiente de execução já está configurado dentro da imagem do container!

Comandos Azure que eu segui no meu computador
# Login
Baixa o coisa para rodar os comando az e loga com a conta da fatec
winget install -e --id Microsoft.AzureCLI
az login

# Criar o Grupo de Recursos
az group create --name rg-purpuzure --location eastus

# Criar o Azure Container Registry (ACR)
az acr create --resource-group rg-purpuzure --name acrpurpuzure --sku Basic --admin-enabled true

# Deu o erro TasksOperationsNotAllowed ?
az acr login --name acrpurpuzure
docker build -t acrpurpuzure.azurecr.io/purpuzure-app:v1 .
docker push acrpurpuzure.azurecr.io/purpuzure-app:v1

# Criar o ambiente para os Container Apps
az containerapp env create --name env-purpuzure --resource-group rg-purpuzure --location eastus

# Por fim
az containerapp create `
  --name app-purpuzure `
  --resource-group rg-purpuzure `
  --environment env-purpuzure `
  --image acrpurpuzure.azurecr.io/purpuzure-app:v1 `
  --target-port 80 `
  --ingress external `
  --registry-server acrpurpuzure.azurecr.io

---

# Parar o app para economizar créditos
az containerapp stop --name app-purpuzure --resource-group rg-purpuzure

# Voltar a rodar o app
az containerapp start --name app-purpuzure --resource-group rg-purpuzure

# Zerar Recursos
az group delete --name rg-purpuzure --yes --no-wait
